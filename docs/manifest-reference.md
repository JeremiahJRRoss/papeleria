A piece has one manifest at the root of its folder: `papeleria.yaml`, or `papeleria.json` with the same fields and values. Field names are lower case, with underscores between words. A field the schema does not list is refused at its line, so a misspelled field is caught.

Each field below has an entry. **Type** is the kind of value. **Required** says whether the field must be written, and when. **Default** is the value the schema assumes when the field is left out; — means it assumes none, and the description says what happens instead. **Allowed** lists the values and limits the schema enforces. **Rules** names the rule that reports each broken limit, and the checks that read the field after the schema; [Rules](#rules) lists every rule that reads a manifest. The example is YAML.

## Common fields

### Fields every piece takes

Every template takes these fields at the top level of its manifest; `schema`, `template` and `title` are required in each.

| Field | Type | Required | Default |
| --- | --- | --- | --- |
| [`schema`](#schema-piece) | a whole number | yes | — |
| [`template`](#template-piece) | text | yes | — |
| [`title`](#title-piece) | [inline Markdown](#inline-markdown) | yes | — |
| [`language`](#language-piece) | text | no | `en` |

#### `schema` (piece)

The manifest format this piece is written for. Write 1. A missing, non-integer or smaller value is a manifest error; a larger one needs a newer Papeleria.

- **Type:** a whole number
- **Required:** yes
- **Default:** —
- **Allowed:** 1 or more
- **Rules:**
  - R09: missing, not a whole number or less than 1
  - R17: a whole number greater than 1, which needs a newer Papeleria; it is then the only finding

```yaml
schema: 1
```

#### `template` (piece)

In a deck: Which template builds this piece. This schema describes the deck template, so the value is deck.

In a comic: Which template builds this piece. This schema describes the comic template, so the value is comic.

In a document: Which template builds this piece. This schema describes the document template, so the value is document.

- **Type:** text
- **Required:** yes
- **Default:** —
- **Allowed:** `deck` in a deck, `comic` in a comic and `document` in a document: the template the manifest is for
- **Rules:**
  - R09: missing, not text or not the name of a template

```yaml
template: comic
```

#### `title` (piece)

In a deck: The deck's cover title, also used as the page title with any line break read as a space. The line at the top of every slide is `register`, not this. Inline Markdown.

In a comic: The comic's title, shown in the register and used as the page title. Inline Markdown.

In a document: The document's takeaway: the one sentence the reader should leave with. Inline Markdown.

- **Type:** [inline Markdown](#inline-markdown)
- **Required:** yes
- **Default:** —
- **Allowed:** at least one visible character
- **Rules:**
  - R09: missing, not text or blank

```yaml
title: The ferry
```

#### `language` (piece)

en (the default) or es. Sets the page language and chooses English or Spanish control labels. The editor itself stays English.

- **Type:** text
- **Required:** no
- **Default:** `en`
- **Allowed:** `en` or `es`
- **Rules:**
  - R09: not text or not one of those values

```yaml
language: es
```

#### `status` (piece)

draft (the default), review, published or withheld. It is shown on the piece. published turns an unfilled [placeholder] into an error; withheld builds a private preview and writes nothing to dist/.

- **Type:** text
- **Required:** no
- **Default:** `draft`
- **Allowed:** one of `draft`, `review`, `published` or `withheld`
- **Rules:**
  - R09: not text or not one of those values

```yaml
status: review
```

- **Allowed:** at least one visible character
- **Rules:**

## Deck

A slide deck in the kit's slide system, schema version 1: a register line, an edition, an optional client logo and at least one slide. Each slide has a layout; the layout decides which fields the slide takes. The build refuses a manifest with an unknown field, so a misspelled field is reported at its line.

### Deck fields

A deck manifest takes the [common fields](#common-fields) and these. Any other field is R09 at its line.

| [`edition`](#edition-deck) | [text](#text) | no | — |
| [`logo`](#logo-deck) | a [logo block](#logo-block) | no | — |
| [`slides`](#slides-deck) | a list of [slides](#slide-fields) | yes | — |

- **Rules:**

- **Type:** [text](#text)

- **Default:** —
- **Allowed:** at least one visible character
- **Rules:**
  - R09: not text or blank

- **Default:** —
- **Allowed:** from 1 to 1,000 slides; each one a [slide](#slide-fields)
- **Rules:**


#### `notes` (slide)

Speaker notes for this slide, written here or loaded from a Markdown file under assets/text/. They show only when notes are turned on.

- **Type:** [Markdown or a text file path](#markdown-or-a-text-file)
- **Required:** no
- **Default:** —
- **Allowed:** at least one visible character; a value that starts with `assets/text/` and ends with `.md` is read as a file and must then be a [text file path](#text-file-path); any other value is the text itself
- **Rules:**
  - R09: not text, blank or a malformed text file path
  - R02: it names a text file that does not exist

```yaml
notes: assets/text/01-cover-notes.md
```

#### `columns` (slide)

The columns of a two, three or four slide, exactly that many, each with a heading and text. Every other layout takes none.

- **Type:** a list of [columns](#column-fields)
- **Required:** yes on `two` (exactly 2), `three` (exactly 3) and `four` (exactly 4) slides; not allowed on any other layout (see [Layouts](#layouts))
- **Default:** —
- **Allowed:** each one a [column](#column-fields)
- **Rules:**
  - R15: missing on a `two`, `three` or `four` slide; given on any other layout; or a list of the wrong length for the layout
  - R09: not a list

```yaml
columns:
  - heading: Context
    text: Audience, purpose, scope, version and owner.
  - heading: Basis
    text: Evidence, assumptions, limitations and terms.
```

#### `chart` (slide)

The chart on a chart slide, drawn from a CSV file. A chart slide takes one chart or one table, never both.

- **Type:** a [chart block](#chart-block)
- **Required:** on a `chart` slide, exactly one of `chart` and `table`; not allowed on any other layout (see [Layouts](#layouts))
- **Default:** —
- **Allowed:** the fields of a [chart block](#chart-block)
- **Rules:**
  - R09: missing on a `chart` slide that has no `table`, given on any other layout, given together with `table` or not a mapping

```yaml
chart:
  type: bar
  data: assets/data/hours-by-phase.csv
  x: phase
  y: hours
  summary: Review took the most hours and delivery the fewest.
```

#### `table` (slide)

The table on a chart slide, in place of a chart.

- **Type:** a [table block](#table-block)
- **Required:** on a `chart` slide, exactly one of `chart` and `table`; not allowed on any other layout (see [Layouts](#layouts))
- **Default:** —
- **Allowed:** the fields of a [table block](#table-block)
- **Rules:**
  - R09: missing on a `chart` slide that has no `chart`, given on any other layout, given together with `chart` or not a mapping

```yaml
table:
  data: assets/data/hours-by-phase.csv
  columns: [phase, hours]
```

#### `image` (slide)

The picture on an image slide. It fills the slide and is cropped to its focal point.

- **Type:** an [image block](#image-block)
- **Required:** yes on an `image` slide; not allowed on any other layout (see [Layouts](#layouts))
- **Default:** —
- **Allowed:** the fields of an [image block](#image-block)
- **Rules:**
  - R09: missing on an `image` slide, given on any other layout or not a mapping

```yaml
image:
  src: assets/images/pier.jpg
  alt: The ferry pier at dawn, empty.

  rights: Studio photograph
```

#### `items` (slide)

The labelled lines of an attributes slide, each with a label and its text. Other layouts take none.

- **Type:** a list of [items](#item-fields)
- **Required:** yes on an `attributes` slide; not allowed on any other layout (see [Layouts](#layouts))
- **Default:** —
- **Allowed:** at least one item; each one an [item](#item-fields)
- **Rules:**
  - R09: missing on an `attributes` slide, given on any other layout, not a list or empty

```yaml
items:
  - label: Voice
    text: Plain and direct.
  - label: Pace
    text: One idea per slide.
```

#### `swatches` (slide)

The colours of a palette slide, each with a name, a #rgb or #rrggbb value and an optional use. Other layouts take none.

- **Type:** a list of [swatches](#swatch-fields)
- **Required:** yes on a `palette` slide; not allowed on any other layout (see [Layouts](#layouts))
- **Default:** —
- **Allowed:** at least one swatch; each one a [swatch](#swatch-fields)
- **Rules:**
  - R09: missing on a `palette` slide, given on any other layout, not a list or empty

```yaml
swatches:
  - name: Process cyan
    value: "#2f7fbf"
    use: section rail
  - name: Paper
    value: "#f7f4ee"
```

### Layouts

The slide's layout. cover and closing open and close the deck on the dark plate; statement holds one idea; two, three and four hold that many columns; chart holds one chart or one table; image holds one picture; attributes holds labelled items; palette holds colour swatches; type and wordmark show the theme's own samples.

Every layout takes `layout` and `title`, and may take `lead`, `footer` and `notes`. The table shows the fields that depend on the layout, from the layout rules of the slide schema: "required" fields must be written, "exactly one of" means one of the pair and never both, and — means the layout does not take the field.

| Layout | `columns` | `chart` | `table` | `image` | `items` | `swatches` |
| --- | --- | --- | --- | --- | --- | --- |
| `cover` | — | — | — | — | — | — |
| `statement` | — | — | — | — | — | — |
| `closing` | — | — | — | — | — | — |
| `two` | required, exactly 2 | — | — | — | — | — |
| `three` | required, exactly 3 | — | — | — | — | — |
| `four` | required, exactly 4 | — | — | — | — | — |
| `chart` | — | exactly one of `chart` and `table` | exactly one of `chart` and `table` | — | — | — |
| `image` | — | — | — | required | — | — |
| `attributes` | — | — | — | — | required | — |
| `palette` | — | — | — | — | — | required |
| `type` | — | — | — | — | — | — |
| `wordmark` | — | — | — | — | — | — |

A slide that breaks its row is reported as: `columns` R15 (C08), `chart` R09 (C09), `table` R09 (C09), `image` R09, `items` R09 and `swatches` R09.

## Comic

A web comic in the studio's Web Comics format, schema version 1: at least one page of art in reading order, each with its alternative text, credit and rights, and the panels a reader steps through. Every panel carries a transcript, so the story reaches a reader who cannot see the art.

### Comic fields

A comic manifest takes the [common fields](#common-fields) and these. Any other field is R09 at its line.

| [`pages`](#pages-comic) | a list of [pages](#page-fields) | yes | — |

#### `format` (comic)

The format label in the register. It defaults to Web Comics, or Web Cómics when the language is es.

- **Type:** [text](#text)
- **Required:** no
- **Default:** —
- **Allowed:** at least one visible character
- **Rules:**
  - R09: not text or blank

```yaml
format: Web Comics
```

#### `pages` (comic)

The pages in reading order, left to right: at least one and at most 1,000. Page N can be linked to as #page-N.

- **Type:** a list of [pages](#page-fields)
- **Required:** yes
- **Default:** —
- **Allowed:** from 1 to 1,000 pages; each one a [page](#page-fields)

```yaml
    alt: A harbour at dawn, seen from the ferry pier.
```

- Any field not listed here is R09 at its line.

- **Default:** —
- **Allowed:** the fields of an [image block](#image-block)

- **Allowed:** an `https:`, `http:`, `mailto:` or `tel:` address, or a relative target; not empty

## Values

The value types that fields share. A field's own entry gives the short form of these limits; the rule that reports a broken one is the field's.

### Text

Text that contains at least one visible character. A value of "" or "   " is rejected, and so is one made only of characters that show nothing: a zero-width space or joiner, a word joiner, a soft hyphen, a byte-order mark, a control character, a Hangul filler or the blank Braille pattern. A blank title, alternative text, transcript, summary, heading, label or name is the same as a missing one.

- **Type:** text
- **Allowed:** at least one visible character. A value made only of spaces, line breaks and characters that show nothing is blank: a zero-width space or joiner, a word joiner, a soft hyphen, a byte-order mark, a control character, a Hangul filler or the blank Braille pattern

### Inline Markdown

One line of Markdown for emphasis, code spans and links. Headings and lists are not allowed here; they belong in a text block. A line break is two trailing spaces or a backslash. Raw HTML is shown as visible text, never executed.

- **Type:** text
- **Allowed:** at least one visible character. A value made only of spaces, line breaks and characters that show nothing is blank: a zero-width space or joiner, a word joiner, a soft hyphen, a byte-order mark, a control character, a Hangul filler or the blank Braille pattern

### Markdown or a text file

Either Markdown written directly in the manifest, or the path of a Markdown file. A value that starts with assets/text/ and ends with .md loads that file, and must then be a well-formed path, like every file path in a manifest; every other value is the text itself. Markdown image syntax is rejected, so that alternative text, credit and rights stay explicit: use an image block.

- **Type:** text
- **Allowed:** at least one visible character. A value made only of spaces, line breaks and characters that show nothing is blank: a zero-width space or joiner, a word joiner, a soft hyphen, a byte-order mark, a control character, a Hangul filler or the blank Braille pattern; a value that starts with `assets/text/` and ends with `.md` is read as a file and must then be a [text file path](#text-file-path); any other value is the text itself

### Text file path

A Markdown file inside assets/text/, written with forward slashes, for example assets/text/summary.md. Folders are allowed. Absolute paths, drive letters, backslashes, .. segments and names starting with a dot are rejected.

- **Type:** text
- **Allowed:** starts with `assets/text/`, may go on through folders, and ends with a file name ending in `.md`, in lower case; every folder and file name starts with an ASCII letter, a digit, `_` or `-` and goes on with those or `.`, and the parts are separated by forward slashes. An absolute path, a drive letter, a backslash, a `..` segment, a space or a name that starts with a dot does not match

### Image path

An image inside assets/images/, for example assets/images/pier.jpg. Allowed extensions are .png, .jpg, .jpeg, .webp and .svg. An SVG is copied unchanged only after it passes the restricted profile; a raster image is resized at build time.

- **Type:** text
- **Allowed:** starts with `assets/images/`, may go on through folders, and ends with a file name ending in `.png`, `.jpg`, `.jpeg`, `.webp` or `.svg`, in lower case; every folder and file name starts with an ASCII letter, a digit, `_` or `-` and goes on with those or `.`, and the parts are separated by forward slashes. An absolute path, a drive letter, a backslash, a `..` segment, a space or a name that starts with a dot does not match

### Logo path

A logo inside assets/images/logos/, for example assets/images/logos/client.svg. Keeping logos in their own folder is what allows a client's mark to travel with the piece while owner marks stay out of it.

- **Type:** text
- **Allowed:** starts with `assets/images/logos/`, may go on through folders, and ends with a file name ending in `.png`, `.jpg`, `.jpeg`, `.webp` or `.svg`, in lower case; every folder and file name starts with an ASCII letter, a digit, `_` or `-` and goes on with those or `.`, and the parts are separated by forward slashes. An absolute path, a drive letter, a backslash, a `..` segment, a space or a name that starts with a dot does not match

### CSV file path

A CSV file directly inside assets/data/, for example assets/data/hours-by-phase.csv. The file is UTF-8, comma separated, uses a decimal point, and its first row is the header.

- **Type:** text
- **Allowed:** starts with `assets/data/` and goes on with a file name ending in `.csv`, in lower case, with no folder in between; the name starts with an ASCII letter, a digit, `_` or `-` and goes on with those or `.`. A path with a folder, a backslash, a space or a name that starts with a dot does not match

### Video path

A video directly inside assets/video/, for example assets/video/loop.mp4. Allowed extensions are .mp4 and .webm. The measured duration must be greater than zero and at most 15 seconds.

- **Type:** text
- **Allowed:** starts with `assets/video/` and goes on with a file name ending in `.mp4` or `.webm`, in lower case, with no folder in between; the name starts with an ASCII letter, a digit, `_` or `-` and goes on with those or `.`. A path with a folder, a backslash, a space or a name that starts with a dot does not match

### Colour

A colour written as #rgb or #rrggbb, for example #2f7fbf.

- **Type:** text
- **Allowed:** `#` followed by exactly three or exactly six hexadecimal digits, `0` to `9` and `a` to `f` in either case, such as `#2f7fbf` or `#fff`

### Link

Where the panel's link goes when the reader chooses it: an https, http, mailto or tel address, a page-relative target, or a fragment such as #page-3. Anything else, including javascript:, data:, //host forms written with any mix of slashes and backslashes and a /path from the root of the site, is rejected. Write the scheme in lower case; the full check happens when the piece is built.

- **Type:** text
- **Allowed:** either an address that starts with `https://`, `http://`, `mailto:` or `tel:`, in lower case, and goes on with at least one more character and no space; or a relative target, such as `#page-3` or `notes.html`, with no colon and no space, that does not start with `/` or `\`; not empty

## Rules

The schema check reports a broken limit as R09 at the field's line (a missing field at its container's, IC01), unless a rule of its own owns the field (D149): the alternative text of an image, a comic page or a logo is R03, and a video's R10; a panel's transcript is R04; a chart's summary is R05; a slide's columns are R15, except a value that is not a list; the numbers of a panel box are R14, except a missing box. Each problem is reported once, by one rule. A manifest whose `schema` is newer than this release is R17 alone, before anything else is checked.

Other checks read the fields once the schema has passed them. Two read the whole piece rather than one field: R01 reports a bracketed placeholder, such as `[Artist]`, left in any text, and R12 an owner-exclusive file copied into the piece. R08 (the generated HTML) and R11 (dependency licences) check the build and the tool, not the manifest, and are not listed.

| Rule | Severity | What it reports | Fields |
