# Trademarks

The code, templates and theme in this package may be licensed openly; the names and marks are not. A code license grants rights in copyright. It grants no rights in the names or the marks, and this file states that explicitly.

## What stays with Ross.moda

| Asset | Treatment |
| --- | --- |
| Ross.moda name, four-tile mark, logos and wordmarks | All rights reserved; not included in this package; never under the code license |
| Papeleria as the name of this tool and this package | A trademark of Ross.moda, marked ™ in the documents and the editor |
| The Papeleria favicon in `theme/marks/` | Part of the Papeleria identity; replace it in a fork |

## Allowed

- Saying that a piece was made with Papeleria, and linking to the project.
- Naming the unmodified project in articles, talks and documentation.
- Using the theme, the templates and the scripts under whatever license the owner sets, with your own name and marks.

## Not allowed

- Using Papeleria or Ross.moda as the name of a fork, a product or a service.
- Using the Ross.moda marks, or the Papeleria favicon, in a fork.
- Implying endorsement by Ross.moda.

## Forks

A fork chooses a new name, replaces the favicon, and sets its own wordmark text before it is published. The templates take the wordmark from the theme, so a fork updates the default settings and replaces the favicon.

This file records intent. It is not legal advice, and registration of the names is a decision for the owner to take with a trademark attorney.

## Build inventory boundary

R12 detects supplied owner-exclusive asset hashes outside brand/. The shipped public theme settings and Papeleria favicon are intentional distribution exceptions; client-provided logos under assets/images/logos are allowed. These exceptions do not grant a fork permission to keep the Papeleria identity. Attribution text naming the source is allowed. See decision D05 in the development record.
