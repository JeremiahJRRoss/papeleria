Adopted / RM-D10, superseding RM-D0406 / 16
Speaker notes & source detail Process values sampled pixel-wise from the recovered master mark: cyan #32bce9, magenta #eb3a96, yellow #f5ee2f, key #050708, set over the standard neutral ramp—paper #fcfcfa, surface #ffffff, ink #1d1d1a, muted #5f5f57, rule #d8d8d1. Section color answers which section this is; it never means good, bad, active, selected, complete, or dangerous, and status colors keep their own separate semantics. No process color is used as text: against paper, cyan measures 2.15:1, magenta 3.67:1, and yellow 1.19:1, all failing WCAG AA, so they serve as fields, rails, plates, and keys, with section-tile labels set in key. Print equivalents remain to be produced against the vendor’s CMYK ICC profile; no ink percentages, Pantone, or spot numbers are asserted, and “CMYK” names the process family and the section system here, not a set of ink percentages. Superseded history, not current guidance: RM-D04 retained six inspected CSS colors—paper #F4F1EA, ink #1F1E1A, muted #69655B, rule #D8D2C5, studio green #4F6E5E, subtle green #E4EBE4—and added deep green #203D32 as an opening-plate extension. RM-D10 supersedes that palette; it is recorded here as history, not as guidance. The packaged exports linked from this deck and from the presentations page—downloads/papeleria-brand-overview-v1.pptx and downloads/papeleria-brand-overview-v1.pdf—are the 1.0.0 exports produced before this correction, and they still carry that withdrawn palette and the Georgia display typography. They are kept as the superseded 1.0.0 record, not as current guidance; re-exporting both against RM-D09 and RM-D10 is an open item. RM-D10 / v1.1.0

Adopted / RM-D10, superseding RM-D0407 / 16
Speaker notes & source detail The repository names Inter/Avenir and Fraunces/Times but does not load those fonts in the inspected source. This kit sets Poppins for display at weight 600, chosen because its constructed geometry matches the mark’s letterforms, and Inter for reading and UI at 18 px body, chosen for screen legibility; monospace remains the system stack for IDs and code. Both families are self-hosted under assets/fonts/ as unicode-range-gated latin and latin-ext woff2, about 170 KB in total, so the kit renders identically offline and from disk with no CDN and no third-party request. Both are licensed under the SIL Open Font License 1.1, which permits commercial use, embedding, and redistribution with the license retained. Superseded history, not current guidance: RM-D04 used Georgia with Times New Roman for display and Arial/Helvetica for reading, and stated that no font files are packaged. Font binaries are now packaged, so that statement no longer describes the kit. Display weight moves from 400 to 600 and negative tracking eases from about -.075em to about -.03em, because tracking tuned for Georgia collapses a geometric sans.
