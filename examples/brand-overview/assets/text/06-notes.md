Process values sampled pixel-wise from the recovered master mark: cyan #32bce9, magenta #eb3a96, yellow #f5ee2f, key #050708, set over the standard neutral ramp—paper #fcfcfa, surface #ffffff, ink #1d1d1a, muted #5f5f57, rule #d8d8d1. Section color answers which section this is; it never means good, bad, active, selected, complete, or dangerous, and status colors keep their own separate semantics. No process color is used as text: against paper, cyan measures 2.15:1, magenta 3.67:1, and yellow 1.19:1, all failing WCAG AA, so they serve as fields, rails, plates, and keys, with section-tile labels set in key. Print equivalents remain to be produced against the vendor’s CMYK ICC profile; no ink percentages, Pantone, or spot numbers are asserted, and “CMYK” names the process family and the section system here, not a set of ink percentages.
